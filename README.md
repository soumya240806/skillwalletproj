# ⚡ EV Market Performance & Insights

A single-file analytics website for the electric vehicle market. It stores EV data in a SQLite database, analyses it with SQL, and presents the results in an interactive dashboard built with Flask and Chart.js.

## Problem Statement
EV manufacturers, consultants and researchers need to understand which vehicle categories, manufacturers and battery technologies drive sales, range and customer satisfaction. This project answers those questions for three users:

| User | Role | Needs |
|------|------|-------|
| Emily Johnson | EV Market Strategy Director | Category sales, top manufacturers, satisfaction, high-growth segments |
| David Chen | Automotive BI Manager | Market share, battery distribution, manufacturing countries, ratings |
| Dr. Sarah Williams | Sustainable Mobility Researcher | Battery comparison, range improvements, production geography |

## Features
- **Dashboard:** 5 KPI cards and 8 charts with category, manufacturer and year filters
- **Story:** 6 data-driven scenes generated automatically from the database
- **Data Explorer:** searchable, sortable, paginated table with CSV download
- **SQL Lab:** read-only SQL console with example queries
- **Performance:** data volume, feature counts and query response times
- **Documentation:** step-by-step development procedure inside the app
- Responsive layout (desktop and mobile)

## Tech Stack
Python 3 · Flask · SQLite · HTML/CSS/JavaScript · Chart.js

## Getting Started
**Requirements:** Python 3.8+ and an internet connection (Chart.js is loaded from a CDN).

```bash
python ev_project_single.py
```
Flask installs automatically if missing. Then open **http://127.0.0.1:5000** in your browser. Press `Ctrl + C` in the terminal to stop the server.

## Development Steps
1. **Problem understanding:** defined the business questions for the three user scenarios.
2. **Data collection:** 2,000 EV records generated by `build_db()` (manufacturer, category, battery type, country, year, sales, range, capacity, rating, price). A real dataset can be swapped in.
3. **Storage:** data loaded into the SQLite table `ev`, with a CSV copy saved.
4. **SQL operations:** `GROUP BY`, `SUM`, `AVG`, subqueries and calculated fields (revenue, market share %, range per kWh, average rating).
5. **Data preparation:** typed columns, consistent categories, derived fields, parameterised filters.
6. **Visualizations and dashboard:** 8 charts and 5 KPIs with three filters.
7. **Story:** 6 scenes covering market size, segments, manufacturers, battery technology, range and satisfaction, and revenue.
8. **Performance testing:** measured row count, charts, filters, calculated fields and average
